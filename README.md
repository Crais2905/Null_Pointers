# Fixer · AI-тріаж логів

**ВАЖЛИВО: У цьому MVP для генерації діагнозів та роботи AI-рушія використано модель Gemini (Gemini API). Будь ласка, враховуйте це під час перевірки (у початкових чернетках ТЗ розглядався Claude, але фінальне рішення реалізовано на Gemini).**

## 📌 Про проєкт
Fixer — це AI-powered інструмент для customer support та розробників. Система приймає сирий лог (разом зі скаргою користувача), перевіряє його детермінованими правилами та AI, ставить діагноз із доказами (точні цитати з логу), знаходить, хто з розробників компетентний це виправити, і створює для нього готове завдання. Людина втручається лише там, де система не впевнена.

**Слоган:** лог на вході — завдання у правильного дева на виході.

## 🛠 Технологічний стек
*   **Frontend (UI/UX):** React + Tailwind CSS
*   **Core Backend (Оркестрація та логіка):** Java 17, Spring Boot, H2 Database (перевірка доказів, маршрутизація, дедуплікація, політика відправки)
*   **AI Engine (Аналіз та діагностика):** Python 3.11, FastAPI, **Gemini API** (маскування PII, парсинг логів, генерація діагнозу та чернетки завдання)

## 📂 Структура репозиторію
*   `/web` — Frontend-частина (екрани інциденту, Inbox розробника, Команда).
*   `/backend` — Java-сервіс (API, управління даними, політики відправки завдань).
*   `/ai` — Python-сервіс (інтеграція з Gemini, детектори логів, маскування даних).
*   `/contracts` — JSON-контракти для взаємодії між сервісами.

## 🚀 Як запустити локально
1. Встановіть необхідні залежності для Java, Python та Node.js.
2. Додайте ваш API ключ Gemini у змінні середовища Python-сервісу (`.env`).
3. Запустіть сервіси згідно з інструкціями у відповідних директоріях (або використовуйте `docker-compose up --build`, якщо налаштовано).
